## Setup and run

1. Install [Godot 4.7](https://godotengine.org/download/).
2. Open Godot and import `new-game-project/project.godot`.
3. Select the project in the Project Manager and click **Run Project** (or press **F6** in the editor).

## Controls

- **Arrow keys** move (hold two for diagonals).
- **Z** interacts with a task console, skips a cutscene and continues on score screens.
- **M** opens the map.
- Keep your torch on a vampire to catch him, then choose **Reveal** or **Kill**.
- In tasks: the mouse (and the keys shown in each task). **Esc** leaves a task.
