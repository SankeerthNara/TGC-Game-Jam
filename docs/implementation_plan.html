MIRROR PAGE

Implementation plan for Hours 12 to 100. In a comic, the light is your weapon and the narrator is cheating.

1. Where we are at Hour 12 (already built and verified)

  • Core loop: a dark comic-studio level where only the area around the hero's torch is lit. The hero walks smoothly in 8 directions. Each level has 5 to 8 interactive tasks that fill a progress bar.
  • 4 generated levels of 8 rooms in a random (non-grid) layout, with rising difficulty, a map screen, checkpoints at each level start, respawn on death, and level and total timers with a split summary.
  • 13 task types: wires, fuse box, lantern code, torch charge, telescope, ink spills, card swipe (classic style) plus comic tasks (order panels, fill speech bubbles, letter sound effects), college tasks (debug code, logic gates, shelve books) and the original light puzzle pages (drag panels, flip mirrors, steer a beam) with the goal-flip, lying-mirror and gutter-bend rule twists.
  • Sabotage and health: risky tasks start a countdown; a fix console must be completed in time or the hero loses a heart. Zero hearts means respawn at the checkpoint.
  • Tooling: level and puzzle validators, headless unit tests, a browser (WebGL) build verified, comic UI, menus, CC0 audio, open fonts.

STRETCH (only after all of the above are playable, in this order): light puzzle rooms in the world (rotate real mirrors to open a door), a torch battery with recharge lamps, reactive music (faster while a timer runs). Cut first if time is short: stretch items, then medals, then the manga and pop-art levels (fallback: palette swaps only), then the boss mirror phase (fallback: a two-phase boss with torch damage only).

Fixed limits: 4 levels (no more), no multiplayer, no save slots, no level editor, no new engine features. Quality over quantity.

4. How the work is split

  • Claude Code: architecture, Saboteur AI, level generator, twist scripting, bug fixing, code review and merges.
  • Antigravity: art direction per genre, UI, shaders and transitions, audio, browser (Playwright) playtests, the itch.io page.
  • ChatGPT / Codex: tests, balance data, documentation, README and CREDITS, small isolated features.
  • Developer (Sankeerth): all design decisions, narrator script and story direction, the playtests, every merge to main. Design choices are logged in docs/DESIGN_LOG.md.
  • Method: each tool works in its own git worktree and owns separate folders, a shared task board (docs/TASKS.md) tracks everything, commits are small and frequent so the history is auditable.

5. Quality, compliance and risks

AreaPlan
StabilityHeadless unit tests for the puzzle model, level validator for every puzzle, a generator test that builds 100+ levels and checks reachability, a Playwright browser run on every milestone build.
AssetsOnly free, CC0, CC BY, open-source or AI-generated assets. Everything listed in CREDITS.md and on the itch.io page. No paid assets.
AI disclosureClaude Code, Antigravity and ChatGPT/Codex are used for code, art, audio and documents. Every use is logged in docs/AI_USAGE.md. Core design and story direction are the developer's.
Code originAll game code is written inside the 100 hours. Only a generic empty Godot project and an editor plugin used for tooling (not part of the game) were present at the start; the plugin is credited.
Risk: Saboteur AI is too hard to tuneKeep the AI simple (patrol, flee from light, freeze in the beam). Fallback: it only triggers sabotage on a fixed schedule and the player can still stop it with the fix console.
Risk: combat is not funBoth fights reuse existing mechanics (torch light, mirrors, hearts) instead of a new combat system. Attacks are slow and readable. Early playtests at Hour 45 (small fight) and Hour 70 (boss). Fallbacks: the small fight becomes a freeze-and-catch moment, the boss drops to two phases without mirrors.
Risk: art style workloadGenres are palette, font and caption swaps over one shared set of procedural shapes. Fallback: two genres instead of four.
Risk: web performance2D lights are limited to the hero's torch; test every milestone in a browser; keep the export under 40 MB.
Risk: AI quota limitsWork is split across three tools with a handoff note on the task board; the developer reassigns tasks to whichever tool has quota left.

6. Definition of done

  • A public itch.io page with a playable browser build of the full 12 to 15 minute game.
  • The README shows the itch.io link, setup, controls and team details. CREDITS and the AI usage log are complete.
  • The final game matches this plan: all committed features present, nothing from the cut list promised.
