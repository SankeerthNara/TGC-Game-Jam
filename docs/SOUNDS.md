# Sound effects: names and when they play

Game code asks for a sound with `EventBus.sound_requested.emit("<name>")`. The sound player
(`scripts/audio/sfx_player.gd`, owned by Codex) maps each name to `assets/audio/sfx_<name>.wav`
and also listens to the existing EventBus signals listed at the bottom. Music is separate
(`scripts/core/music_director.gd`); the classic and opera tracks are generated by
`tools/make_music.py`, and the four synced 720p layers by `tools/make_synthwave.py`.

Style: comic, punchy and readable in the mix. Most effects are under 0.4 seconds; longer signals
and power cues have a deliberate tail. All WAVs are synthesised from scratch by `tools/make_sfx.py`
(NumPy only) and released CC0. Regenerate with `python tools/make_sfx.py`.

The 720p music is an original dark synthwave arrangement at 100 BPM in A minor. Its 16-bar,
38.4-second loop is split into four sample-synced 22050 Hz mono layers; import each with
`edit/loop_mode=2` so Godot loops the layers together.

## Requested by name (`sound_requested`)

| Name | When | Feel |
|---|---|---|
| `task_success` | a task mini-game is solved | bright two-note "ding-ding" |
| `task_mistake` | a wrong move inside a task (also any task message flash) | soft low "bonk" |
| `vampire_spotted` | the torch catches a vampire (before the cutscene) | hiss + sting |
| `reveal_friend` | Reveal on the friend | warm magical swell |
| `reveal_villain` | Reveal on the villain | evil laugh-like stab |
| `kill` | Kill on either vampire | whoosh + thud (ejection) |
| `key_get` | a level is finished and a key is won | key jingle |
| `explosion` | the bomb goes off; any "BOOM" word in a cutscene | big boom, long tail |
| `friend_assigned` | F gives a task to the friend | short "okay!" blip |
| `friend_done` | the friend finishes a task | happy chirp |
| `page_turn` | a story cutscene turns the page | paper whoosh |
| `comic_pop` | a sound-effect word pops up in a cutscene | pop / punch |
| `key_click` | a key turns in the bomb room door | metal click |
| `chase_jump` | jump in a chase | springy "boing" (light) |
| `chase_bounce` | bounce pad in the ball chase | big "BOING" |
| `chase_fall` | fell / crashed back to a flag | falling whistle |
| `chase_checkpoint` | reached a flag | small fanfare |
| `chase_hit` | crashed into an obstacle / hit by an enemy | crash |
| `chase_vault` | clean vault over a crate | swoosh |
| `chase_slide` | slide under a pipe | scrape |
| `chase_win` | the villain is caught | triumphant hit |
| `chase_lose` | the villain escaped | descending "wah-wah" |
| `web_attach` | a light-line attaches to a hook | "thwip" |
| `web_shoot` | web shot fired | short "pew" |
| `web_hit` | web shot hits an enemy | splat |

## The Editions (`sound_requested`)

| Name | When | Feel |
|---|---|---|
| `punch` | a light hero strike | compact body thump |
| `punch_heavy` | a heavy strike | deep, weighty impact |
| `kick` | a kick attack | short low-frequency thump |
| `counter_flash` | an enemy's eye signals a counter window | rising electronic ping |
| `counter_hit` | a counter or parry lands | bright ring over a heavy hit |
| `enemy_grunt` | an enemy reacts to damage | low, descending voiced growl |
| `glitch` | the image tears or pixelates | gated digital sweep |
| `static` | comms or screen signal breaks up | brief radio-noise burst |
| `comms_beep` | an incoming comms call | three retro console beeps |
| `comms_dead` | the comms signal dies | descending disconnected tones |
| `resolution_change` | the player changes image resolution | ascending digital whoosh and sparkle |
| `cursor_click` | the player clicks a menu option | crisp interface click |
| `typewriter` | a letter appears in the credits | mechanical double key strike |
| `credits_whoosh` | credits move to the next card | soft paper sweep |
| `light_swell` | the finale restores the light | warm, rising chord |

## From existing EventBus signals

| Signal | Sound name to use |
|---|---|
| `task_started` | `task_open` (console beep) |
| `sabotage_started` | `sabotage_alarm` (siren, about 1 s) |
| `sabotage_resolved` | `sabotage_fixed` (relief chime) |
| `sabotage_failed` | `heart_lost` (hurt hit) |
| `player_died` | `death` (sad drop) |
| `item_collected`, `trade_made`, `door_unlocked` | matching interaction sounds (supported for the retained town hooks) |

Level complete and failure stingers are played by the music director (`sting_win`, `sting_fail`).
